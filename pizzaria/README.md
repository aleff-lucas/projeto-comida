🍕 Sistema de Gerenciamento de Pizzaria

Projeto desenvolvido com o objetivo de criar um sistema web para gerenciamento de uma pizzaria.

🚀 Tecnologias utilizadas

HTML5

CSS3

JavaScript

Node.js

Express

SQLite

📂 Estrutura do projeto

frontend/ — Interface do sistema.

backend/ — Servidor e lógica da aplicação.

backend/controllers/ — Controle das funcionalidades.

backend/routes/ — Rotas da aplicação.

backend/models/ — Modelos de dados.

backend/database/ — Configuração do banco de dados.

⚙️ Funcionalidades em desenvolvimento

Cadastro de pizzas.

Consulta de pizzas cadastradas.

Atualização de informações.

Gerenciamento de estoque.

Integração entre frontend e backend.

🎯 Objetivo

Desenvolver um sistema completo de gerenciamento de pizzaria, colocando em prática conhecimentos de desenvolvimento web e programação backend.
